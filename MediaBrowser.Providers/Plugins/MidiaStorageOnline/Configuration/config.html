Midia Storage Online

Baixa lista M3U e gera arquivos .strm ou baixa as midias para filmes e series.

Ative para tratar a lista como fonte mundial e aplicar o mesmo fluxo de classificação/validação.
URL opcional quando o storage mundial estiver ativo; caso contrario, use aqui a fonte da lista.
URL de um guide.xml gerado pelo iptv-org/epg ou outro XMLTV. Os canais precisam ter tvg-id compatível com o XMLTV.
Quando ativado, baixa o guia de programação automaticamente durante a sincronização usando os tvg-id da lista M3U. Ignorado se uma URL manual de EPG for fornecida acima.
Filtra as fontes de EPG pelo idioma informado. Padrão: pt.
Deixe em branco ou 0 para usar o limite automatico do sistema. Quanto maior, mais links sao validados ao mesmo tempo.
Deixe em branco para usar o padrao: [ProgramData]/midia-online/strm/
strm cria atalhos para a URL original. download baixa o arquivo de midia e grava localmente.

M3U Canais (usar no TV ao Vivo):

Ja registrado automaticamente no Dashboard > TV Ao Vivo.

XMLTV/EPG:

Esse XMLTV pode ser usado no Live TV > XMLTV do MulletaFlix ou deixado para registro automatico do plugin.
